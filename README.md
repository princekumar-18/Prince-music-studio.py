# Prince-music-studio.py
Prince Music Studio is an advanced desktop music player built using Python, PySide6, and VLC.
✨ Key Features
1) Music Player
   
Play, pause, stop, next and previous.
Supports MP3, WAV, FLAC, AAC and OGG.

2) Audio Equalizer
   
10-band equalizer.
Bass and treble control.
Stereo balance and volume adjustment.
Playback speed control.

3) Music Visualizer
   
Real-time audio spectrum analyzer.
Animated sound wave visualization.
Oscilloscope display.

4) Music Library
   
Automatically organizes music files.
Search and filter songs.
Tracks recently played songs.
Maintains play counts and favourites.

5) Album Artwork
   
Displays album covers.
Supports music metadata editing.
Displays song information.

6) Playlists
   
Create custom playlists.
Add or remove songs.
Organize music into different categories.

7) Internet Radio
   
Stream live radio stations from around the world.

8) Smart Recommendations
   
Recommends songs based on listening history.
Keeps track of favourite music.

9) Modern Interface
    
Spotify-inspired design.
Sidebar navigation.
Clean and user-friendly desktop interface.
